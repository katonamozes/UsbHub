# UsbHub

This is a basic usb hub that transfers 1 usb port into 4. I used this tutorial to make it: https://jams.hackclub.com/batch/usb-hub/part-1#Start%20a%20new%20project I did change some stuff like I used a different processor because the one that is in the tutorial isn't available on JLCPCB so I couldn't order it cheaply. I also added 2 more usb's to make it more useful. I also added a custume silkscreen so that it is more personal.
